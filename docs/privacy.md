# 개인정보처리방침

**서비스명**: 커피렌즈 (Coffilens)
**시행일**: 2026-05-03
**최종 개정일**: 2026-05-03

커피렌즈(이하 "서비스")는 「개인정보 보호법」 등 관련 법령을 준수하며, 이용자의 개인정보를 보호하기 위해 다음과 같이 개인정보처리방침을 수립·공개합니다.

---

## 1. 수집하는 개인정보의 항목 및 수집 방법

### 1-1. 수집하지 않는 정보 (명시)

서비스는 다음 정보를 **일체 수집하지 않습니다**:

- 이름, 생년월일, 성별, 연락처, 이메일 주소
- 주민등록번호, 여권번호, 운전면허번호
- 주소, 위치 정보 (GPS, IP 기반 위치)
- 결제 정보 (카드번호, 계좌번호)
- 통신 정보 (통화내역, 문자 내역)
- 디바이스 영구 식별값 (광고 ID, 디바이스 fingerprint)

### 1-2. 디바이스 내 저장 정보 (외부 전송 없음)

다음 정보는 사용자의 디바이스 내 IndexedDB 에 **로컬 저장**되며, **외부 서버로 전송되지 않습니다**:

| 항목 | 설명 | 저장 기간 |
|---|---|---|
| 분쇄도 측정 결과 | D10/D50/D90 (μm), 균일도, 미분 비율, 입자 수, 신뢰도 점수 | 사용자 직접 삭제 시까지 |
| 측정 시점 썸네일 | 촬영한 사진의 축소본 (~50KB JPEG) | 사용자 직접 삭제 시까지 |
| 측정 메타데이터 | 동전 종류 (100원/500원), 측정 일시, 분석 시간 | 사용자 직접 삭제 시까지 |

이 정보는 디바이스 저장 공간이 부족한 경우 자동 정리될 수 있습니다 (오래된 기록부터 순차 삭제).

### 1-3. 토스 SDK 를 통한 수집 정보 (이벤트 로그)

토스 미니앱 표준 SDK 의 이벤트 로그 기능을 통해 다음 **익명** 정보가 토스에 전송됩니다:

| 이벤트 종류 | 수집 항목 |
|---|---|
| 앱 진입 | 디바이스 분류 (iOS/Android × 메모리 등급), 세션 ID, 시각 |
| 측정 시도/성공/실패 | 동전 종류, 분석 소요 시간, 신뢰도 점수, 실패 사유 분류 |
| OpenCV 로드 실패 | 실패 원인 분류 (네트워크/권한/타임아웃) |
| 광고 노출/클릭/로드 실패 | 광고 슬롯 위치 (홈/결과), 광고 그룹 ID, 오류 코드 |

**세션 ID 특성**:
- 앱 진입 시마다 새로 생성되는 무작위 식별자 (UUID)
- 디바이스/사용자 영구 식별과 무관 — 앱 종료 시 폐기
- 동일 사용자의 다른 세션 간 연결 불가

**디바이스 분류** 는 4단계 그룹 (iOS 고/저성능, Android 고/저성능) 으로만 분류되며, 개별 디바이스 식별이 불가능합니다.

### 1-4. 촬영 이미지 처리

촬영한 이미지는 다음과 같이 처리됩니다:

1. 카메라로 촬영 → 디바이스 메모리에서만 처리
2. OpenCV.js (디바이스 내 동작) 로 분쇄도 분석
3. 분석 후 원본 이미지 즉시 폐기
4. 썸네일 (~50KB) 만 IndexedDB 에 로컬 저장

**원본 이미지는 외부 서버로 전송되지 않으며, 분석 직후 메모리에서 삭제됩니다.**

## 2. 개인정보의 수집·이용 목적

서비스는 1-3 항목의 익명 정보를 다음 목적으로만 이용합니다:

- 서비스 안정성 모니터링 (오류 발생 빈도, 분석 실패율)
- 서비스 품질 개선 (디바이스별 성능 진단)
- 광고 효과 분석 (노출/클릭률 산출)

---

## 3. 개인정보의 보유 및 이용 기간

| 분류 | 보유 기간 |
|---|---|
| 디바이스 내 측정 기록 | 사용자가 직접 삭제하거나 디바이스 저장 공간 부족 시까지 |
| 토스 이벤트 로그 | 토스 정책에 따름 (별도 안내 시 갱신) |

사용자는 앱 내 "측정 기록" 화면에서 개별 기록을 직접 삭제할 수 있습니다.

---

## 4. 개인정보의 제3자 제공

서비스는 이용자의 개인정보를 외부에 제공하지 않습니다.

토스 SDK 로 전송되는 익명 이벤트 로그는 토스의 표준 미니앱 SDK 동작 범위 내에서 처리되며, 별도의 제3자 제공이 발생하지 않습니다.

---

## 5. 개인정보 처리의 위탁

서비스는 다음과 같이 개인정보 처리를 위탁합니다:

| 수탁업체 | 위탁 업무 | 보유 및 이용 기간 |
|---|---|---|
| 비바리퍼블리카 (토스) | 미니앱 호스팅 및 익명 이벤트 로그 처리 | 토스 정책에 따름 |

위탁 업체 외에 개인정보 처리를 위탁하는 제3자는 없습니다.

---

## 6. 이용자의 권리

이용자는 다음과 같은 권리를 행사할 수 있습니다:

- **측정 기록 열람**: 앱 내 "측정 기록" 화면에서 직접 확인
- **측정 기록 삭제**: 측정 기록 카드의 삭제 버튼으로 즉시 삭제 (2단계 확인)
- **전체 데이터 삭제**: 토스 앱에서 커피렌즈 미니앱 종료 후 디바이스 저장소에서 자동 정리됨
- **이벤트 로그 거부**: 토스 앱의 개인정보 설정에서 통합 관리

---

## 7. 개인정보의 안전성 확보 조치

서비스는 다음 조치를 적용합니다:

- **외부 통신 미사용**: 분석은 전적으로 디바이스 내 OpenCV.js 로 수행. 별도 서버 호출 없음
- **이미지 외부 전송 금지**: 촬영한 원본 이미지는 디바이스를 떠나지 않음
- **무작위 세션 ID**: 디바이스 또는 사용자 식별 불가능한 일회성 식별자만 사용
- **로컬 저장만 사용**: 측정 기록은 디바이스 IndexedDB 에만 저장
- **HTTPS 통신**: 토스 SDK 통신은 HTTPS 표준 보안 적용

---

## 8. 자동 수집 거부 권리

서비스는 사용자의 디바이스 식별값, 광고 ID, 쿠키 등 자동 추적 정보를 수집하지 않습니다.

토스 SDK 의 이벤트 로그는 토스 앱의 개인정보 설정에서 통합 관리할 수 있습니다.
