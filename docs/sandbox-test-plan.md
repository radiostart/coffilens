# Sandbox 회귀 테스트 plan

> **목적**: 출시 전 실제 토스 앱 (sandbox) 에서 단위 테스트로 못 잡는 통합 이슈 발견.
> **방식**: 수동 — 각 시나리오를 실 폰으로 실행하면서 ✓/✗/메모 기록.

## A. 핵심 측정 흐름

### A1. Happy path — 500원 V60 분쇄도 측정 + 저장

**선행**: 흰 종이 위에 500원 + 분쇄 커피 펴기, 균일 조명.

| 단계 | 기대 동작 |
|---|---|
| 1 | 토스 앱 → 커피렌즈 진입 → intro 화면 표시 |
| 2 | 측정 시작 → coin-select 진입 |
| 3 | 500원 선택 → capture-guide 표시 |
| 4 | "촬영 시작" → 카메라 화면 + 권한 prompt (첫 진입 시) |
| 5 | 권한 허용 → 라이브 프리뷰 |
| 6 | 셔터 → coin-locate 진입 |
| 7 | 동전 위치 탭 → analyzing 진입 |
| 8 | 진행률 6단계 표시 + 100% 도달 |
| 9 | result 화면 — D50/D10/D90, 신뢰도, 히스토그램 |
| 10 | "측정 저장" → "✓ 측정 기록이 저장되었어요" 토스트 |
| 11 | "홈으로" → home 화면, 저장된 기록 표시 |

**관측 항목**:
- 분석 시간 (목표 < 5초 p50)
- 메모리 peak (Safari/Chrome dev tools 또는 토스 dev menu)
- progress bar 가 단계별로 변하는지 (점프 X)

### A2. 100원 동전 측정

A1 와 동일 단계, 100원 선택.
- 동전 인식 정상 (학 동전 디자인)
- 직경 환산 정확 (D50 값이 500원 측정과 ±10% 이내)

### A3. Multi-shot averaging (정확도 ↑)

| 단계 | 기대 동작 |
|---|---|
| 1 | 측정 1회 완료 → result 화면 |
| 2 | "✨ 한 번 더 측정 (정확도 ↑)" 클릭 |
| 3 | "같은 분쇄도인가요?" confirm 모달 노출 |
| 4 | "네, 같은 분쇄도예요" → /camera 로 이동 |
| 5 | 같은 분쇄도 재촬영 + 분석 |
| 6 | result 화면에 "✨ 2회 측정 평균 (정확도 ↑)" 배지 노출 |
| 7 | D-값이 1회 측정 대비 변동 (±50µm 이내가 정상) |
| 8 | "측정 저장" → 저장된 기록 카드에 동일 결과 |
| 9 | 홈에서 그 기록 클릭 → archive view 도 "2회 측정 평균" 배지 |

### A4. "다시 촬영 (새 측정)" 은 누적 비움

- result 화면에서 "다시 촬영 (새 측정)" 클릭 → 카메라 진입
- 분석 결과 → "1회 측정" 배지 (없음 == 1회) 또는 배지 없음
- 이전 multi-shot 누적이 자동 비워졌는지 검증

## B. 에러 시나리오

### B1. no_coin (동전 없는 사진)

| 단계 | 기대 동작 |
|---|---|
| 1 | 동전 없이 분쇄 커피만 촬영 |
| 2 | 분석 후 "동전을 찾지 못했어요" 화면 |
| 3 | "이렇게 해보세요" 가이드 표시 |
| 4 | "자세한 진단 보기 ▼" 클릭 (있을 경우) |
| 5 | 검출된 원형 후보 + 위치 + 이유 노출 (또는 0개) |

### B2. no_coin (그림자 진 동전)

- 동전 위에 photographer 그림자 만들고 촬영
- 진단 ⚠️ 메시지 — "동전 위에 그림자가 졌어요" 또는 "윤곽이 흐려요"
- 재촬영 후 정상 동작

### B3. multi_coin (동전 2개 이상)

- 동전 2개 같이 촬영
- "동전이 여러 개 보여요" 화면
- 검출된 개수 표시

### B4. partial_coin (가장자리 잘림)

- 동전이 사진 가장자리에 절반만 보이게 촬영
- "동전이 잘렸어요" 화면

### B5. blur (흔들린 사진)

- 일부러 흔들면서 촬영
- "사진이 흔들렸어요" + Laplacian variance 진단 표시
- "다시 촬영하기" 후 정상 동작

### B6. low_brightness (어두운 환경)

- 어두운 곳에서 촬영
- "너무 어두워요" + 평균 밝기 표시
- 자동으로 분석 X (preflight 단계에서 reject)

### B7. no_particles (원두 없음 / 너무 적음)

- 동전만 단독 촬영 (원두 없음)
- "분쇄 입자를 찾지 못했어요" 화면

### B8. 카메라 권한 거부

- 첫 진입 시 카메라 권한 거부
- "권한 거부됨" 안내 화면 + "토스 설정" 안내
- 토스 설정에서 권한 다시 허용 후 → 정상 진입

### B9. OpenCV 로드 실패 (네트워크)

- 비행기 모드 ON 상태로 첫 측정 시도
- "분석 엔진 로드 실패" 화면 + 네트워크 안내
- 비행기 모드 OFF 후 재시도 → 정상 동작 (캐시 또는 재로드)

## C. 성능 / 리소스

### C1. 분석 시간 측정

| 디바이스 | 1280px 캐시 안 된 첫 측정 | 캐시된 두 번째 측정 |
|---|---|---|
| iOS high | 목표 < 5s p50 | 목표 < 2s p50 |
| iOS low | 목표 < 8s p50 | 목표 < 3s p50 |
| Android high | 목표 < 5s p50 | 목표 < 2s p50 |
| Android low | 목표 < 10s p50 | 목표 < 4s p50 |

### C2. 메모리 사용량

- WebView dev tools 또는 토스 dev 모니터링
- 측정 중 peak 메모리 (목표 < 150MB, downsample 적용 후 ~70MB 예상)
- 측정 후 즉시 메모리 회수 (GC 작동)
- Multi-shot 3회 후에도 누적 누수 없는지 검증 (3회 측정 모두 동일 peak)

### C3. 분석 취소 응답성

- 분석 중 "취소하고 홈으로" 버튼 즉시 동작
- HoughCircles 진행 중 (coin 단계) 에서도 즉시 home 으로 (Web Worker terminate)
- 화면 응답 < 0.5초

### C4. 분석 중 백그라운드 전환

- 분석 중 토스 앱 백그라운드 → 다른 앱 → 토스 복귀
- 분석 자동 재개 또는 화면 정리 (crash X)

## D. 데이터 영속성

### D1. 측정 기록 저장 / 조회

- 5건 측정 후 모두 저장
- 토스 앱 종료 → 재진입
- 홈에서 5건 모두 표시
- 각 기록 클릭 → archive view (그래프 + 가이드 모두 재현)

### D2. 측정 기록 삭제

- 기록 카드 우측 ✕ → "삭제?" 토글 → 5초 내 다시 ✕ → 즉시 삭제
- 5초 안 누르면 자동 취소
- archive view 에서 "이 기록 삭제" 버튼도 동일 동작

### D3. Storage quota 자동 정리

- 50건 이상 저장 (의도적 over-fill)
- 가장 오래된 기록 자동 삭제 + "오래된 기록 N개를 정리했어요" 토스트
- 신규 측정 정상 저장

## E. UX 마감

### E1. 모든 화면 한국어 + 액션 명확

체크리스트 — 다음 화면이 모두 한국어로 표시되고 다음 액션이 분명:
- intro / home / coin-select / capture-guide / camera / coin-locate
- analyzing / result / errorDetails (10가지)

### E2. 디스클레이머 노출

- result 화면 하단에 "측정값은 상대 비교용입니다" disclaimer 항상 표시

### E3. Brewing guide 카테고리 정확

| D50 (μm) | 라벨 | 추천 도구 |
|---|---|---|
| < 500 | 미세 | 에스프레소, 모카포트 |
| 500-900 | 중간 | 핸드드립 (V60/Aeropress 등) |
| ≥ 900 | 거침 | 프렌치프레스, 콜드브루 |

핸드드립 분쇄도 측정 후 "중간" + "핸드드립" 추천 노출 검증.

### E4. 핸드드립 최적화 banner

- capture-guide 화면 상단에 "이 측정은 핸드드립 분쇄도에 최적화" banner 표시

### E5. 미세 (espresso) 영역 caveat

- 의도적으로 매우 fine 한 분쇄도 측정 (D50 < 500)
- result 의 "어떻게 추출할까요?" 섹션에 "핸드드립 분쇄도에 최적화" caveat 노출

## F. 광고 (출시 후 adGroupId 발급된 경우만)

> **현재 상태**: adGroupId 미발급 → banner 미노출 (fail-soft 정상). 발급 후 별도 sandbox 회귀.

### F1. (미래) Home banner 노출

- 홈 진입 → records 하단 광고 banner 표시
- 토스 콘솔에 `ad_impression` 1건 기록 (slotId="home")

### F2. (미래) Result banner 노출

- 측정 완료 후 result → disclaimer 하단 banner 표시
- `ad_impression` 1건 (slotId="result")

### F3. (미래) Click 추적

- banner 클릭 → 광고 외부 페이지 이동
- 토스 콘솔에 `ad_click` 1건

### F4. (미래) Load fail

- 의도적으로 잘못된 adGroupId 입력
- banner 빈 영역 (`:empty { display:none }` 으로 시각 흔적 X)
- 토스 콘솔에 `ad_load_fail` + errorCode 기록

## G. 다양한 환경 변수

### G1. 다양한 조명

| 조명 | 결과 기대치 |
|---|---|
| 직사광 (외부, 그림자 강) | 동전 검출 가능 (strong gradient bypass) |
| 흐린 날 / 그늘 | 가장 안정적 |
| 형광등 (실내, 균일) | 안정적 |
| 백열등 / 따뜻한 LED (단일 광원) | 가능, 약간 정확도 ↓ |
| 어두운 (촛불 등) | low_brightness reject |

### G2. 다양한 종이 색

| 배경 | 결과 |
|---|---|
| 흰 A4 | 표준, 안정 |
| 약간 누런 종이 | 가능 (contrast 충분) |
| 어두운 색 종이 | no_particles reject (정상) |

### G3. 다양한 분쇄도

| 분쇄도 | 측정 | 카테고리 |
|---|---|---|
| 에스프레소 영역 | D50 ~250-400µm | 미세 (caveat 노출) |
| V60 medium | D50 ~600-900µm | 중간 |
| French Press | D50 ~1000-1300µm | 거침 |

## H. 텔레메트리 검증 (출시 D-day 직전)

토스 콘솔에서 다음 이벤트가 정상 기록되는지 확인:

| Event | 발생 조건 |
|---|---|
| `app_open` | 앱 진입 시 1건 |
| `measurement_attempt` | 동전 선택 시 1건 |
| `measurement_success` | 정상 측정 완료 시 1건 |
| `measurement_fail` | 에러 발생 시 1건 (failReason 분류 표시) |
| `opencv_load_fail` | 비행기 모드 측정 시도 시 1건 |
| `ad_impression` (출시 후) | adGroupId 발급 후 banner 첫 노출 |
| `ad_click` (출시 후) | banner 클릭 시 |
| `ad_load_fail` (출시 후) | 잘못된 adGroupId 시 |
